# JavaScript starter

Copy to `submissions/<your-id>/`. Set the manifest id to that directory name and fill in your own metadata and concept. No TypeScript or framework is required. The neutral wiring is not a contest idea.

Run `node scripts/dev-play.ts your-id` from the repo root and open the printed URL. Restart after edits. Return cleanup from mount; honor the abort signal and theme/mute callbacks when relevant.

The contract is in `sdk/README.md`. Use the shared pnpm checks before submitting.
