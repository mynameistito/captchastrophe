# Security

Report gallery-origin, iframe boundary, auth or voting vulnerabilities through GitHub's private vulnerability reporting in this repository's Security tab (enabled). Don't put secrets or working attacks against real players in a public issue.

Rewriting your own captcha in devtools is not a production bot-protection bypass. This is a browser toy.

Until the hosting boundary is deployed and tested, don't run strangers' submissions on the trusted gallery origin. Fork builds have no deployment credentials. Human acceptance remains required.
